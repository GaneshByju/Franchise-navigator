1. WHAT ALL TESTING WE HAVE USED IN THE PROJECT (WITH SHORT DESCRIPTIONS)
--------------------------------------------------------------------------------
• End-to-End (E2E) Browser UI Testing:
  Automated browser execution simulating real user interactions (clicking, 
  typing, navigating, tab switching, and modal opening) with screenshot 
  and DOM verification.

• Tab-Scoped Session Isolation Testing:
  Verification ensuring login credentials stored in sessionStorage do not 
  bleed into other browser tabs, preventing unauthorized access when links 
  are copied to new tabs.

• Navigation & History (Popstate) Trap Testing:
  Testing browser Back and Forward button interactions to guarantee that 
  navigating back while logged in never causes a blank screen, closes active 
  modals safely, and locks the user within the protected session until the 
  "Sign Out" button is clicked.

• Client & Server-Side Form Validation Testing:
  Multi-tier input verification testing regex formats, email structures, 
  password strengths (min 6 characters), password match popups, 10-digit 
  phone constraints, and required fields.

• Role-Based Access Control (RBAC) Testing:
  Security testing ensuring Investor, Franchiser, and Admin portals are strictly 
  segregated (e.g., rejecting attempts to register admin accounts or access 
  privileged audit endpoints).

• Trademark & Brand Conflict Algorithmic Testing:
  Testing string similarity, phonetic matching, and acronym collision algorithms 
  (Levenshtein distance) to prevent trademark infringement during franchise creation.

• Financial DSS Feasibility Algorithm Testing:
  Mathematical verification of the 0–100 Feasibility Scoring Engine, Payback 
  Period (months), Break-Even calculations, ROI percentages, and Capex breakdowns.

• REST API Endpoint & Error Status Code Testing:
  Integration tests verifying HTTP response codes (200 OK, 400 Bad Request, 
  401 Unauthorized, 403 Forbidden, 404 Not Found) across all backend endpoints.

• TypeScript Static Analysis & Production Build Testing:
  Running "tsc --noEmit" and "vite build" to ensure zero syntax, bundling, or 
  type errors across all React components.

• Django Framework Integrity Checks:
  Running "python manage.py check" to guarantee zero schema, model, URL, or 
  runtime syntax conflicts.
